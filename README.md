# 萌萌合成（H5 离线版）

一个参考《InfiniteCraft》玩法的离线 H5 合成小游戏：以 **金/木/水/火/土** 为基础元素，通过拖拽合成不断解锁新元素。UI 走 **Q 版可爱贴纸风**（SVG 矢量图标 + 统一配色），同时适配鼠标与触控。

## 运行方式

直接用浏览器打开 `index.html` 即可游玩（推荐 Chrome / Edge）。

> 如果你用的是本地静态服务器（可选）：把该目录作为静态站点根目录即可。

## 玩法

- 从左侧 **元素库** 拖一个元素到画布
- 把一个贴纸 **拖到另一个贴纸上** → 命中配方即可获得结果，并（如果是第一次）解锁新元素
- 顶部按钮：
  - **撤销**：仅移除上一次合成产生的“结果贴纸”（不会回滚解锁）
  - **整理**：把画布贴纸排成整齐网格
  - **清空**：清空画布
  - **导入/导出**：存档 JSON

## 配方说明

- 本项目是离线版：不接 AI。
- 内置两层配方：
  1) 少量“主线”逻辑配方（帮助玩家快速解锁关键系统元素）
  2) 大量“收藏向”配方（**1000+**），用于持续解锁反馈
- 若未命中配方，引擎还会尝试少量“通用规则”来生成结果，让合成体验更接近无限扩展。

## 后续扩展（可选）

如需更商业级的内容深度（更强逻辑链路、更强可解释性、更精细稀有度/任务/成就），建议把配方与元素元数据拆成独立 JSON，并做一套内容编辑/校验流程。
